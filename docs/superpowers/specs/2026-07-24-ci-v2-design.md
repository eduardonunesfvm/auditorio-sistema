# CI v2 - De/Para + Editor Rico + Tipos de Documento

**Data:** 2026-07-24 | **Status:** Aprovado

## 1. Visão Geral

Refatorar a CI para suportar dois tipos de documento, campos De/Para, editor rico com tabelas, e rodapés condicionais com assinatura e recebimento.

## 2. Tipos de Documento

| Tipo | Valor | Título PDF |
|---|---|---|
| Comunicação Interna | `comunicacao_interna` | COMUNICAÇÃO INTERNA Nº X |
| Solicitação de Material | `solicitacao_material` | COMUNICAÇÃO INTERNA - SOLICITAÇÃO DE MATERIAL Nº X |

Numeração (`numero_ci`) única e compartilhada entre os dois tipos (1-100 cíclico).

## 3. Modelo de Dados

### 3.1 Tabela `comunicacoes_internas` - novas colunas

| Coluna | Tipo | Null | Descrição |
|---|---|---|---|
| `tipo` | VARCHAR(50) | NOT NULL | `comunicacao_interna` ou `solicitacao_material` |
| `de` | VARCHAR(255) | NOT NULL | Setor/órgão de origem |
| `para` | VARCHAR(255) | NOT NULL | Setor/órgão de destino |
| `nome_signatario` | VARCHAR(255) | NULL | Nome do signatário (CI normal) |
| `sobrenome_signatario` | VARCHAR(255) | NULL | Sobrenome (CI normal) |
| `cargo_signatario` | VARCHAR(255) | NULL | Cargo (CI normal) |

`descricao` permanece como `Text` mas passa a armazenar HTML.

### 3.2 Migration

```sql
ALTER TABLE comunicacoes_internas 
  ADD COLUMN tipo VARCHAR(50) NOT NULL DEFAULT 'comunicacao_interna',
  ADD COLUMN de VARCHAR(255) NOT NULL DEFAULT '',
  ADD COLUMN para VARCHAR(255) NOT NULL DEFAULT '',
  ADD COLUMN nome_signatario VARCHAR(255) NULL,
  ADD COLUMN sobrenome_signatario VARCHAR(255) NULL,
  ADD COLUMN cargo_signatario VARCHAR(255) NULL;
```

### 3.3 Dados da Érika (hardcoded, constante no service)

## 4. Schemas Pydantic

```python
class ComunicacaoInternaCreate(BaseModel):
    tipo: str                                    # comunicacao_interna | solicitacao_material
    de: str = Field(..., max_length=255, min_length=1)
    para: str = Field(..., max_length=255, min_length=1)
    titulo: str = Field(..., max_length=255, min_length=1)
    descricao: str = Field(..., min_length=1)     # HTML
    data: date
    nome_signatario: Optional[str] = None
    sobrenome_signatario: Optional[str] = None
    cargo_signatario: Optional[str] = None

class ComunicacaoInternaResponse(BaseModel):
    # todos os campos existentes + de, para, tipo,
    # nome_signatario, sobrenome_signatario, cargo_signatario

class ComunicacaoInternaUpdate(BaseModel):
    # todos os campos editaveis como Optional
```

Validacao: se `tipo == 'comunicacao_interna'`, `nome_signatario`, `sobrenome_signatario` e `cargo_signatario` sao obrigatorios.

## 5. Template PDF

### 5.1 Cabecalho (comum)

```
[BANNER]

COMUNICACAO INTERNA Nº {numero_ci}
ou
COMUNICACAO INTERNA - SOLICITACAO DE MATERIAL Nº {numero_ci}

Data: {data}
De: {de}
Para: {para}
Titulo: {titulo}

Descricao:
{{ descricao | safe }}
```

### 5.2 Rodape - CI Normal

```
Sendo o que tenho para o momento, desde ja
agradeco a vossa valorosa e prestimosa atencao.

___________________________________
{nome} {sobrenome}
{cargo}
```

### 5.3 Rodape - Solicitacao de Material

```

___________________________________
Erika Siqueira Souza Battistelli

[Espaco para carimbo]

Recebimento em: _____/_____/______
Assinatura e carimbo (ou nome completo): ___________
```

## 6. Service (`service.py`)

`_render_template` recebe: `numero_ci, tipo, de, para, titulo, descricao_html, data_str, nome_signatario, sobrenome_signatario, cargo_signatario`

Se `tipo == 'solicitacao_material'`, injeta dados da Erika e renderiza o bloco de recebimento.

## 7. Frontend

### 7.1 HTML
- Select `ci-tipo` no topo do formulario
- Inputs `ci-de`, `ci-para`
- Div `ci-signatario-fields` com `ci-nome`, `ci-sobrenome`, `ci-cargo` - visivel apenas se tipo = CI normal
- `ci-descricao` vira uma `<div>` inicializada pelo TinyMCE

### 7.2 TinyMCE
Carregado via CDN:
```html
<script src="https://cdn.tiny.cloud/1/no-api-key/tinymce/6/tinymce.min.js"></script>
```
Toolbar: bold, italic, underline, bullist, numlist, table, undo, redo.

### 7.3 JS
- `switchTab("ci")`: inicializa TinyMCE se ainda nao inicializado
- Ao mudar `ci-tipo`: mostrar/esconder campos de signatario
- Submit: `tinymce.get("ci-descricao").getContent()` para obter HTML
- Edicao: `tinymce.get("ci-descricao").setContent(html)` para preencher
- Tabela: colunas No, Tipo, Titulo, De, Para, Data, Emitido por, Acoes
- Busca textual: inclui `de`, `para`, signatario
